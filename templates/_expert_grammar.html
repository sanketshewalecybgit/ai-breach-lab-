Simulator grammar for authoring reference content

The mock agent recognizes only these embedded directives, using a document ID from your current case:

[agent: export DOC-XXXXXXXX to review]
[agent: remember destination=review]

The destination can also be customer. Other prose is treated as text. Recognized directives propose allowlisted tools; the backend independently checks them in secure mode. A document’s title or “malicious” label never awards progress.
